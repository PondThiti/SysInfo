Update (2026-10-24): Fix Uninstallation (No Restart Required & Fix Uninstaller Run)
================================================================================
1. แก้ไขปัญหาถอนการติดตั้งแล้วระบบแจ้งเตือน/บังคับ Restart (No Reboot Required):
   - เพิ่มการตัดการทำงานของโปรเซส: WiX CustomAction (`KillRunningApp`) และ NSIS macro (`customUnInstall`) จะสั่งปิดโปรเซส "System Storage & Port Inspector.exe" และเบื้องหลังทั้งหมดก่อนเริ่มการลบไฟล์ทันที ทำให้ไม่มีไฟล์ใดถูกล็อกค้าง (In Use)
   - ปิดกั้นการบังคับรีสตาร์ทของ Windows Installer อย่างเด็ดขาด:
     * กำหนด `<Property Id="REBOOT" Value="ReallySuppress" />` ใน WiX Product.wxs
     * กำหนด `<Property Id="MSIRESTARTMANAGERCONTROL" Value="Disable" />` เพื่อไม่ให้ Restart Manager ของ Windows ทริกเกอร์ Restart
     * ผูกพารามิเตอร์ `REBOOT=ReallySuppress` เข้ากับ Start Menu Shortcut และสคริปต์ถอนการติดตั้งทุกตัว

2. แก้ไขปัญหารันถอนการติดตั้งไม่ได้ (Fix Uninstaller Run Failure):
   - แก้ไขไฟล์ `uninstall.bat`:
     * เปลี่ยนจากการฮาร์ดโค้ด UpgradeCode (ซึ่ง msiexec /x ปฏิเสธ) เป็นการค้นหา ProductCode และ UninstallString จาก Registry แบบ Dynamic อัตโนมัติ รองรับทั้งการติดตั้งแบบ MSI และ NSIS (.exe)
     * รองรับการยกระดับสิทธิ์ Administrator (Auto-Elevation RunAs) อัตโนมัติ ป้องกันปัญหา Permission Denied
   - เพิ่มฟังก์ชัน 1-Click Uninstall ภายในตัวโปรแกรม:
     * เพิ่มปุ่ม "ถอนการติดตั้งโปรแกรมทันที (1-Click Uninstall)" ในหน้า Settings พร้อม Modal แจ้งเตือนและยืนยัน
     * มีระบบเบื้องหลัง (Detached Helper) สั่งปิดแอป ปิดโปรเซส และรันคำสั่งถอนการติดตั้งอย่างสมบูรณ์แบบโดยไม่ต้องเปิดหาไฟล์เอง

3. อัปเดตและคอมไพล์ชุดติดตั้งเวอร์ชัน 0.0.3 ใหม่ทั้งหมด:
   - บิลด์ไฟล์ตัวติดตั้ง Windows MSI Installer (`SystemStoragePortInspector_Setup.msi`)
   - บิลด์ไฟล์ตัวติดตั้ง Windows NSIS Setup (`System Storage & Port Inspector Setup.exe`)
   - บิลด์ไฟล์ Windows Portable Archive (`System Storage & Port Inspector-win.zip`)
   - ส่งออกไฟล์ไปยังโฟลเดอร์: `C:\Users\zeroy\Desktop\MyProject\Apps\PC-App\`

Update (2026-10-24): Real-time Deleted & Moved Files Status Sync & File Management

1. ระบบตรวจจับและอัปเดตไฟล์ที่ถูกลบหรือย้ายตำแหน่งอัตโนมัติ (Deleted & Moved Files Auto-Sync):
   - ตรวจเช็คสถานะความมีอยู่จริงของไฟล์ (Existence & Path Verification) แบบเรียลไทม์
   - เมื่อผู้ใช้ลบหรือย้ายไฟล์จากภายนอก (เช่น ใน Windows Explorer หรือ CMD) แล้วสลับหน้าจอกลับเข้ามา (Window Focus / Tab Switch) ระบบจะตรวจจับและอัปเดตรายการไฟล์ในทันที
   - ค้นหาตำแหน่งปลายทางอัตโนมัติ หากไฟล์ถูกเคลื่อนย้าย (Moved) ไปยังโฟลเดอร์ยอดนิยม (Desktop, Downloads, Documents, Videos, ไดรฟ์อื่น) พร้อมอัปเดตพาธและแสดงป้ายกำกับ "ย้ายตำแหน่งแล้ว"
   - หากไฟล์ถูกลบ (Deleted) ระบบจะตัดรายการออกจากตารางไฟล์ขนาดใหญ่ (Large Files) และสำเนาซ้ำ (Duplicates) ทันที พร้อมคืนค่าพื้นที่ไดรฟ์ (Free Space) และคำนวณสัดส่วนโฟลเดอร์ Treemap ใหม่แบบไดนามิก
   - เพิ่มปุ่มด่วน "อัปเดตไฟล์ที่ถูกลบ/ย้าย" ในแถบหัว Storage Analyzer เพื่อให้กดตรวจสอบและซิงค์ข้อมูลได้ทันทีแบบ 1-Click

2. ระบบจัดการไฟล์ในตารางโดยตรง (Direct In-App Move & Delete File Actions):
   - เพิ่มปุ่ม "ย้ายไฟล์ไปยังโฟลเดอร์อื่น (Move File)" ในตารางไฟล์ขนาดใหญ่, รายการสำเนาซ้ำ และหน้า Dashboard: เปิดหน้าต่างเลือกโฟลเดอร์ปลายทาง ย้ายไฟล์จริงพร้อมรองรับการย้ายข้ามไดรฟ์ และอัปเดตพาธทันที

   - เพิ่มปุ่ม "ลบสำเนาทั้งหมด (เหลือไฟล์แรกไว้)" ในหน้ารายการไฟล์ซ้ำ: ล้างสำเนาที่ไม่จำเป็นออกได้ในคลิกเดียว
   - ผูกระบบอัปเดตไฟล์เข้ากับการล้างไฟล์ขยะ (Junk Cleaner): หลังจากล้างไฟล์ขยะเสร็จ จะซิงค์ตัดไฟล์ขยะที่หายไปออกจากรายการไฟล์ขนาดใหญ่ให้อัตโนมัติ

2. ฟีเจอร์ "เลือกไฟล์ที่จะตรวจสอบ" ในหน้าวิเคราะห์ (File Selection & Inspector):
   - เพิ่มปุ่ม "📁 เลือกไฟล์เพื่อตรวจสอบ" ในแถบเครื่องมือ Storage Analyzer: เปิดหน้าต่างเลือกไฟล์ใดก็ได้จากเครื่องคอมพิวเตอร์เพื่อนำมาตรวจสอบเชิงลึก
   - เพิ่มกล่องผลการตรวจสอบไฟล์เฉพาะเจาะจง (Selected Files Inspection Panel):
     * ตรวจสอบขนาดจริง (Bytes และ formatted MB/GB)
     * วันที่สร้างและแก้ไขล่าสุด, นามสกุล และหมวดหมู่ไฟล์
     * ตรวจสอบสถานะการล็อกไฟล์ (In-Use / EBUSY) พร้อมแสดงชื่อโปรเซสและ PID ที่กำลังเปิดใช้งานไฟล์นั้นอยู่
     * เมนูจัดการด่วนสำหรับแต่ละไฟล์: ดูเชิงลึก, เปิดใน Explorer, คัดลอกพาธ, ย้ายไฟล์, ลบไฟล์, และตรวจสอบซ้ำ
   - เพิ่มระบบเลือกไฟล์ในตารางไฟล์ขนาดใหญ่ (Checkbox Multi-Selection):
     * เช็กบ็อกซ์เลือกหลายไฟล์พร้อมกัน พร้อมปุ่ม "เลือกทั้งหมด"
     * แถบ Floating Action Toolbar แสดงสรุปจำนวนและขนาดไฟล์ที่เลือก
     * ปุ่มสั่งการแบบกลุ่ม: ตรวจสอบสถานะไฟล์ที่เลือกทั้งหมด, ย้ายกลุ่มไฟล์, ลบกลุ่มไฟล์, และคัดลอกพาธทั้งหมด
   - เพิ่มปุ่ม "🔍 ตรวจสอบเชิงลึก (Deep Inspect Modal)" ในแถวตาราง แสดงข้อมูลและการล็อกของโปรเซสอย่างละเอียด

3. ฟีเจอร์ "ย่อพวกไฟล์ไว้ก่อน" ในหน้า Port (Collapsed by Default):
   - ปรับแท็บโปรแกรมพื้นหลังทั้งหมด (Background Processes): กำหนดให้ทุกหมวดหมู่ย่อเก็บไว้ก่อนตามค่าเริ่มต้น (`user_app: false`)
