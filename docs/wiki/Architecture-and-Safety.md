# สถาปัตยกรรมและความปลอดภัยระดับระบบ (Architecture & Safety)

## 1. การย้ายข้ามไดรฟ์อย่างปลอดภัย (Atomic Cross-Drive Move)

บนระบบปฏิบัติการ Windows การสั่ง `rename` ข้ามไดรฟ์ (เช่น จาก `C:` ไป `D:`) จะเกิดข้อผิดพลาด `EXDEV` (Cross-device link):

### กระบวนการที่ SysInfo ปฏิบัติ:
1. **Copy:** คัดลอกไฟล์ไปยังโฟลเดอร์ปลายทางด้วยชื่อชั่วคราว (`${dest}.tmp_${uuid}`)
2. **Verify Size:** ตรวจสอบขนาดไฟล์ปลายทางว่าตรงกับขนาดต้นทางทุกไบต์
3. **Verify SHA-256 Hash:** คำนวณ Hash ตรวจสอบความถูกต้องสมบูรณ์ของข้อมูล 100%
4. **Preserve Metadata:** คืนค่าวันเวลาแก้ไข (`mtime`) และเวลาเข้าถึง (`atime`) ของไฟล์เดิม
5. **Rename Temp:** เปลี่ยนชื่อไฟล์ชั่วคราวเป็นชื่อปลายทางจริง
6. **Unlink Source:** ลบไฟล์ต้นทางออกหลังจากยืนยันความถูกต้องแล้วเท่านั้น
7. **Fail-Safe Rollback:** หากเกิดข้อผิดพลาดในขั้นตอนใดขั้นตอนหนึ่ง ระบบจะลบไฟล์ชั่วคราวทิ้งทันที และคงไฟล์ต้นทางไว้ ไม่ทำให้ไฟล์เสียหายหรือสูญหายกลางคัน

## 2. ขอบเขตความปลอดภัย (Path Boundaries)

* **ป้องกันไดเรกทอรีระบบ:** ไม่อนุญาตให้จัดระเบียบไฟล์เข้าหรือออกจาก `C:\Windows`, `C:\Program Files`, `C:\Program Files (x86)`, `C:\Recovery`, `$Recycle.Bin`, `System Volume Information`
* **ป้องกันโปรเจกต์นักพัฒนา:** หากโฟลเดอร์มีไฟล์เครื่องหมายโปรเจกต์ (`.git`, `package.json`, `Cargo.toml`, `go.mod`) ระบบจะปฏิเสธการแยกไฟล์ออกจากกัน เพื่อป้องกันโปรเจกต์พัง
* **รองรับ Windows Long Paths:** จัดการกับข้อจำกัด 260 ตัวอักษรของ Windows ด้วย extended prefix (`\\?\`)
* **ป้องกันชื่อไฟล์สงวน:** กรองและป้องกันชื่อไฟล์ที่ระบบ Windows ไม่อนุญาต เช่น `CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`
