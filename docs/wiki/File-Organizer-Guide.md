# คู่มือระบบจัดระเบียบไฟล์อัจฉริยะ (File Organizer Guide)

ระบบ **File Organizer** ใน SysInfo v0.10.3 ช่วยแก้ปัญหาไฟล์กระจัดกระจายในโฟลเดอร์ต่างๆ เช่น Downloads, Desktop หรือโฟลเดอร์โปรเจกต์ โดยทำงานผ่าน **Rule Engine** และมี **Undo Journal** เป็นหัวใจหลักเพื่อรับประกันว่าจะไม่มีไฟล์สูญหาย

---

## 1. วิธีใช้งานเบื้องต้น (Quick Start)

1. **เลือกโฟลเดอร์ต้นทาง (Source Directory):**
   - คลิกปุ่ม **"เลือกโฟลเดอร์"** เพื่อระบุตำแหน่ง เช่น `C:\Users\User\Downloads`
   - หรือคลิกปุ่มทางลัด **📥 Downloads** หรือ **🖥️ Desktop**
2. **เลือกโฟลเดอร์ปลายทางหลัก (Target Base Directory):**
   - ติ๊กตัวเลือก **"ใช้โฟลเดอร์เดียวกับต้นทาง"** หากต้องการสร้างโฟลเดอร์ย่อยในที่เดิม
   - หรือเลือกโฟลเดอร์ปลายทางอื่น เช่น ข้ามไดรฟ์ `D:\Organized`
3. **เลือกกฎหรือพรีเซ็ต (Rule Presets):**
   - มี 4 พรีเซ็ตมาตรฐาน:
     * 📁 **จัดตามประเภทไฟล์ (By File Type):** แยก `Images/`, `Documents/`, `Videos/`, `Audio/`, `Archives/`, `Executables/`, `Code/`, `GameAssets/`
     * 📅 **จัดตามปีและเดือน (By Date: YYYY/MM):** เช่น `2026/10`
     * 📥 **จัดระเบียบโฟลเดอร์ Downloads:** แยกเอกสาร สื่อ ซิป โปรแกรมติดตั้งตามปี
     * 🛠️ **จัดระเบียบ Dev & Game Assets:** แยก Asset bundles, Source code, logs
4. **คลิก "สแกนและดูตัวอย่าง (Dry-Run Preview)":**
   - ตาราง Preview จะแสดงรายการไฟล์ต้นทางพร้อมเป้าหมายปลายทางที่จะย้ายไป
   - ระบบจะตรวจจับข้อขัดแย้ง (Conflict) เช่น ชื่อไฟล์ซ้ำ หรือเนื้อหาซ้ำเป๊ะ
5. **กดยืนยันการย้ายไฟล์ (Execute Move):**
   - ทุกขั้นตอนจะถูกบันทึกลง Undo Journal

---

## 2. การจัดการเมื่อชื่อไฟล์ซ้ำ (Conflict Handling)

ระบบมีตัวเลือกจัดการเมื่อปลายทางมีไฟล์ชื่อเดียวกันอยู่แล้ว:

* **Auto Rename (`file (1).ext`):** เติมเลขลำดับอัตโนมัติ ไม่เขียนทับไฟล์เดิม
* **Recycle Duplicate (เช็ค Hash):** หากคำนวณ SHA-256 Hash แล้วพบว่าเนื้อหาเหมือนกัน 100% ระบบจะเสนอให้ส่งสำเนาซ้ำลง Windows Recycle Bin
* **Skip:** ข้ามไฟล์นั้น ไม่ทำการย้าย
* **Overwrite:** เขียนทับไฟล์เดิม (ต้องระมัดระวัง)

---

## 3. การกดย้อนกลับ (Undo Journal)

หัวใจสำคัญที่สุดของ File Organizer คือความปลอดภัย:

* ทุกครั้งที่มีการย้ายไฟล์ ระบบจะบันทึก Batch ID, วันเวลา, พาธต้นทางเดิม, พาธปลายทาง, ขนาดไฟล์ และ mtime
* ไปที่แท็บ **"ประวัติ & Undo"**
* คลิกปุ่ม **"↩️ ย้อนกลับทั้งชุด (Undo Batch)"**
* ระบบจะทำการย้ายไฟล์ทั้งหมดกลับสู่ตำแหน่งต้นทางเดิม พร้อมคืนค่า timestamp (mtime) ให้เหมือนเดิม 100%

---

## 4. ล้างโฟลเดอร์ว่างเปล่า (Empty Folder Cleanup)

หลังจากย้ายไฟล์ออกหมดแล้ว โฟลเดอร์ต้นทางอาจมีโฟลเดอร์ย่อยว่างเปล่าหลงเหลืออยู่ ระบบจะแสดงหน้าต่างถามว่าต้องการลบโฟลเดอร์ว่างหรือไม่ ผู้ใช้สามารถกดล้างโฟลเดอร์ว่างได้ในคลิกเดียว
