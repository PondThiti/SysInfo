# Rule Engine & ตัวแปร Template

## 1. ตัวแปรใน Template ปลายทาง

คุณสามารถปรับแต่งโครงสร้างโฟลเดอร์ปลายทางได้โดยใช้ตัวแปร Template ดังนี้:

| ตัวแปร | ความหมาย | ตัวอย่างผลลัพธ์ |
|---|---|---|
| `{type}` | หมวดหมู่ไฟล์ (Images, Documents, Videos, ฯลฯ) | `Images` |
| `{ext}` | นามสกุลไฟล์ (ตัดจุดออก) | `png`, `pdf`, `zip` |
| `{year}` | ปี ค.ศ. 4 หลัก (จากเวลาแก้ไขหรือสร้าง) | `2026` |
| `{month}` | เดือน 2 หลัก (01-12) | `10` |
| `{day}` | วันที่ 2 หลัก (01-31) | `25` |
| `{name}` | ชื่อไฟล์เดิม (ตัดนามสกุลออก) | `report_final` |
| `{counter}` | เลขลำดับ 2 หลัก (01, 02, 03...) | `01` |
| `{size}` | ขนาดไฟล์จัดรูปแบบ | `15.5MB` |

### ตัวอย่าง Template ยอดนิยม:
* `{type}` → `Images/photo.jpg`, `Documents/contract.pdf`
* `{year}/{month}` → `2026/10/photo.jpg`
* `{type}/{year}` → `Documents/2026/report.pdf`
* `Backups/{year}-{month}` → `Backups/2026-10/archive.zip`

## 2. การเปลี่ยนชื่อกลุ่มไฟล์ (Bulk Rename)

ระบบ Bulk Rename ช่วยให้คุณเปลี่ยนชื่อไฟล์หลายรายการพร้อมกันได้อย่างเป็นระเบียบ:

* รองรับตัวแปร `{name}`, `{date}`, `{year}`, `{month}`, `{counter}`
* มีตาราง Live Preview แสดง "ชื่อเดิม" เปรียบเทียบกับ "ชื่อใหม่ที่จะเปลี่ยน" ก่อนกดยืนยันจริง
